# Pairwise — UI Design Guide

> **Status:** draft (WS-02). ใช้กับทุกหน้าที่จะสร้าง — landing page ปัจจุบันยังใช้สี slate ของ Tailwind
> และจะย้ายมาใช้ token ในไฟล์นี้เมื่อเริ่มทำ UI จริง
>
> ที่มาของสี: ภาพ *Main Color* และ *Secondary Colors* ของ KMITL ที่ทีมใช้เป็นแนวทาง ·
> ที่มาของกฎหน้าจอ: [prd.md](prd.md) §7.5 (Evaluation UI), §13 (NFR), §14.2 (Anonymity), §15 (Accessibility)

## 1. สี (Color)

### 1.1 สีหลักและสีรอง — ค่าจากแนวทางของสถาบัน

| บทบาท | ชื่อ | HEX | RGB | CMYK | อื่น ๆ |
|---|---|---|---|---|---|
| **Main** | Orange | `#E35205` | 227 82 5 | 0 76 100 0 | PANTONE 166C · DIC 1511 |
| Secondary | White | `#FFFFFF` | 255 255 255 | 0 0 0 0 | |
| Secondary | Gray | `#666666` | 102 102 102 | 60 51 51 20 | |
| Secondary | Black | `#000000` | 0 0 0 | 75 68 67 90 | |

### 1.2 Contrast ที่ตรวจแล้ว (WCAG 2.2)

PRD FR-A11Y-03 บังคับ **≥ 4.5:1 สำหรับข้อความ** และ **≥ 3:1 สำหรับ UI component**
ค่าด้านล่างคำนวณด้วยสูตร relative luminance ของ WCAG

| สีหน้า / สีพื้น | Contrast | ข้อความปกติ (4.5) | ข้อความใหญ่ / UI (3.0) |
|---|:---:|:---:|:---:|
| Black on White | 21.00:1 | ✅ | ✅ |
| Gray `#666666` on White | 5.74:1 | ✅ | ✅ |
| White on Gray `#666666` | 5.74:1 | ✅ | ✅ |
| **Orange `#E35205` on White** | **3.84:1** | ❌ | ✅ |
| **White on Orange `#E35205`** | **3.84:1** | ❌ | ✅ |
| Black on Orange `#E35205` | 5.48:1 | ✅ | ✅ |
| Gray `#666666` on Black | 3.66:1 | ❌ | ✅ |
| Orange-dark `#CD4A05` on White | 4.59:1 | ✅ | ✅ |

> **กฎสำคัญ:** สีส้มหลัก `#E35205` **ห้ามใช้เป็นสีตัวอักษรขนาดปกติบนพื้นขาว** และ **ห้ามวางตัวอักษรขาวขนาดปกติบนพื้นส้ม**
> — ใช้ได้กับตัวอักษรใหญ่ (≥ 24 px ปกติ หรือ ≥ 18.66 px ตัวหนา), เส้นขอบ, ไอคอน, focus ring และแถบตกแต่ง
> ถ้าต้องการตัวอักษรสีส้มขนาดปกติ (เช่น link) ให้ใช้ `#CD4A05` ซึ่งเป็นเฉดเข้มขึ้นของสีเดียวกันที่ผ่าน 4.5:1
> (`#CD4A05` คำนวณขึ้นเพื่อ accessibility — ไม่ใช่ค่าจากแนวทางของสถาบัน)

### 1.3 Design tokens

เพิ่มใน `src/index.css` ตอนเริ่มทำ UI จริง (Tailwind 4 สร้าง class เช่น `bg-primary`, `text-muted` ให้อัตโนมัติ):

```css
@import "tailwindcss";

@theme {
  --color-primary: #e35205;       /* Main — พื้นปุ่ม, แถบ, ขอบ, focus ring */
  --color-primary-text: #cd4a05;  /* ตัวอักษรส้มขนาดปกติบนพื้นขาว (4.59:1) */
  --color-ink: #000000;           /* ตัวอักษรหลัก, หัวข้อ */
  --color-muted: #666666;         /* ตัวอักษรรอง, label, คำอธิบาย */
  --color-surface: #ffffff;       /* พื้นหน้าและพื้นการ์ด */
}
```

### 1.4 ใช้สีอะไรกับอะไร

| องค์ประกอบ | สี |
|---|---|
| พื้นหน้า, พื้นการ์ด | `surface` (White) |
| หัวข้อ, ตัวอักษรหลัก | `ink` (Black) |
| label, คำอธิบาย, timestamp | `muted` (Gray) |
| ปุ่มหลัก (Submit, Publish) | พื้น `primary` + ตัวอักษร `ink` (5.48:1) |
| link ในเนื้อหา | `primary-text` + ขีดเส้นใต้ |
| ตัวเลือกที่ถูกเลือก, focus ring, progress bar | `primary` (เป็น UI component ใช้เกณฑ์ 3:1) |
| แถบ header / footer | พื้น `primary` — ถ้ามีตัวอักษรในแถบ ใช้ `ink` หรือตัวหนา ≥ 18.66 px ถ้าเป็นสีขาว |

สี error / success / warning ยังไม่มีในแนวทางของสถาบัน — เลือกเพิ่มได้ แต่ต้องผ่าน 4.5:1 และ
**ห้ามสื่อความหมายด้วยสีอย่างเดียว** ต้องมีไอคอนหรือข้อความประกอบเสมอ (FR-A11Y-02)

## 2. รูปแบบภาพ (Visual style)

ยึดตามลักษณะของภาพแนวทางสี:

| องค์ประกอบในภาพ | นำมาใช้เป็น |
|---|---|
| กล่องสีมุมมน ขอบบาง มีเงานุ่ม ๆ | **การ์ด:** `rounded-2xl` · ขอบ 1 px สี `ink` หรือ `muted` · `shadow-md` |
| หัวข้อ "MAIN COLOR" ตัวหนา ตัวใหญ่ | **หัวข้อ section:** ตัวหนา สี `ink` (ภาษาอังกฤษใช้ตัวพิมพ์ใหญ่ได้ ภาษาไทยใช้ขนาดแทน) |
| รายการ `label : value` จัดแนวตรงกัน | **ข้อมูลแบบ key-value** (เช่น deadline, คะแนน, participation): label สี `muted` ซ้าย, ค่าสี `ink` ชิดแนวเดียวกัน |
| แถบสีส้มเต็มความกว้างด้านล่าง | **แถบ footer (หรือ header)** พื้น `primary` |
| พื้นหลังโทนกระดาษสีอ่อน | ใช้พื้น `surface` สีขาวเป็นหลัก — ถ้าจะใช้พื้น off-white ต้องคำนวณ contrast ใหม่ทุกคู่สี |

## 3. ตัวอักษร (Typography)

- UI เป็นภาษาไทย (NFR-I18N-01) — font ต้องรองรับภาษาไทยครบ ทั้งสระบน-ล่างและวรรณยุกต์
- ทีมยังไม่ได้เลือก font — ระหว่างนี้ใช้ `system-ui, sans-serif`
- ตัวอักษรเนื้อหา **≥ 16 px** · line-height **≥ 1.6** (ภาษาไทยมีสระบน-ล่าง ต้องมีที่ว่างมากกว่าภาษาอังกฤษ)
- หัวข้อ: ตัวหนา สี `ink` · ข้อความรอง: สี `muted` แต่ไม่เล็กกว่า 14 px

---

## 4. Layout

- **Mobile-first** — ออกแบบที่ความกว้าง 320 px ก่อน แล้วค่อยขยาย (NFR-COMPAT-01/02)
- ทุกฟังก์ชันต้องใช้ได้ครบที่ความกว้าง ≥ 320 px ห้ามมี scroll แนวนอนทั้งหน้า
- เนื้อหากว้างสุด ~ `max-w-4xl` บนจอใหญ่ เพื่อให้อ่านง่าย

## 5. หน้า Evaluation — ส่วนที่สำคัญที่สุด

หน้านี้คือที่นักศึกษาใช้เวลาเกือบทั้งหมด (เป้า ≤ 15 นาทีต่อ assignment — M2)

### 5.1 การ์ด comparison

```
┌─────────────────────────────────────┐
│ User Experience          3 / 5 ✓    │  ← ชื่อ criterion + progress (FR-EVAL-07)
├─────────────────────────────────────┤
│  กลุ่ม Aurora        กลุ่ม Borealis  │  ← ชื่อ item สองฝั่ง (ซ้าย/ขวาสุ่มแล้ว — FR-PAIR-08)
│  [ดูผลงาน ↗]         [ดูผลงาน ↗]    │  ← link ไป artifact (FR-EVAL-02)
│                                     │
│  ◯───◯───◯───◯───◯───◯              │  ← 6 ตัวเลือก ไม่มีตัวกลาง (FR-EVAL-03)
│  ซ้ายดีกว่ามาก      ขวาดีกว่ามาก     │
└─────────────────────────────────────┘
```
(จาก PRD §7.5)

### 5.2 ปุ่มเลือก 6 ระดับ

| ตัวเลือก | ข้อความบนปุ่ม |
|:---:|---|
| 1 | ซ้ายดีกว่ามาก |
| 2 | ซ้ายดีกว่า |
| 3 | ซ้ายดีกว่าเล็กน้อย |
| 4 | ขวาดีกว่าเล็กน้อย |
| 5 | ขวาดีกว่า |
| 6 | ขวาดีกว่ามาก |

- ใช้ radio group ตาม WAI-ARIA APG — เลื่อนด้วยปุ่มลูกศรได้ และมี group label เป็นชื่อสองฝั่ง (FR-A11Y-01)
- **ทุกตัวเลือกมีข้อความ** ไม่ใช่แค่ตำแหน่งหรือสี (FR-EVAL-03, FR-A11Y-02)
- พื้นที่กดของแต่ละปุ่ม **≥ 24 × 24 px** ตาม WCAG (FR-A11Y-04) — แนะนำ 44 × 44 px บนมือถือ
- ตัวที่ถูกเลือก: เติมสี `primary` **และ** มีเครื่องหมาย ✓ หรือตัวหนา (ไม่ใช้สีอย่างเดียว)
- Focus ring มองเห็นชัด 2 px สี `primary` (FR-A11Y-05)

### 5.3 สถานะและการส่ง

| องค์ประกอบ | กฎ | Requirement |
|---|---|---|
| สถานะ autosave | "บันทึกแล้ว เมื่อ HH:MM" สี `muted` · ประกาศผ่าน `aria-live="polite"` | FR-EVAL-04, FR-A11Y-06 |
| Progress | `X / Y` ต่อ criterion และรวมทั้งหน้า | FR-EVAL-07 |
| ปุ่ม Submit | กดได้ตลอด แม้ตอบไม่ครบ — ก่อนยืนยันแสดงจำนวนที่ยังไม่ตอบ | FR-EVAL-05 |
| Countdown | แสดงเมื่อเหลือ < 48 ชั่วโมง | FR-EVAL-10 |
| หลัง deadline | คำตอบแสดงแบบ read-only · ปุ่ม Submit หายไป พร้อมข้อความบอกเหตุผล | FR-EVAL-08 |
| ไม่มี artifact link | แสดงข้อความว่าอาจารย์ยังไม่ได้ระบุ | FR-EVAL-02 |
| กลุ่ม ≤ 2 คน | ไม่แสดงหน้า Individual Evaluation และอธิบายเหตุผล | FR-EVAL-12 |

| กฎ | Requirement |

## 7. Checklist ก่อนส่ง PR ที่แตะ UI

- [ ] ใช้ token จากข้อ 1.3 ไม่ hard-code สี
- [ ] ข้อความขนาดปกติทุกจุดผ่าน 4.5:1 (ดูตาราง 1.2) — ไม่มีตัวอักษรส้ม `#E35205` ขนาดปกติบนพื้นขาว
- [ ] ใช้งานได้ครบที่ความกว้าง 320 px
- [ ] ใช้ได้ด้วย keyboard อย่างเดียว และเห็น focus ทุกจุด
- [ ] ความหมายไม่ได้สื่อด้วยสีอย่างเดียว
- [ ] element ที่ test อ้างถึงมี `data-testid`
