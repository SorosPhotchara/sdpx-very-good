## 1. Group Evaluation (mobile-first, 320 px)

หน้าที่นักศึกษาใช้เวลากับมันมากที่สุด · ทุก criterion อยู่หน้าเดียว (FR-EVAL-01)

```
│  └──────────────┴──────────────┘   │

│   1    2    3    4    5    6       │  ปุ่มละ ≥ 24×24 px  FR-A11Y-04
```

**สิ่งที่คนมักออกแบบผิดตรงนี้**

- **ใส่ปุ่ม "เท่ากัน" ตรงกลาง** — D1 ห้ามไว้ เพราะมันคือปุ่มที่คนกดเวลาไม่อยากคิด
- **แสดงเรียงตาม id** — ตำแหน่งซ้าย/ขวาต้องสุ่มทุกครั้ง (D8/FR-PAIR-08)
  และต้องบันทึกว่าสุ่มออกมาเป็นอะไร ไม่งั้นแปลผลกลับไม่ได้
- **disable ปุ่ม Submit จนกว่าจะตอบครบ** — FR-EVAL-05 บอกให้เปิดไว้เสมอ
  แล้วแค่บอกจำนวนที่ยังไม่ตอบ

## 2. My Score (นักศึกษา)

หน้าที่ต้องระวัง privacy มากที่สุดในระบบ

```
┌────────────────────────────────────┐
│ PairEval                    [nok ▾]│
├────────────────────────────────────┤
│ Assignment 2 — คะแนนของฉัน          │
│                                    │
│ ┌────────────────────────────────┐ │
│ │ ⚠ ชั่วคราว — อาจเปลี่ยนแปลงได้  │ │  FR-SCORE-07
│ └────────────────────────────────┘ │  แสดงทุกที่ที่คะแนนปรากฏ
│                                    │
│   คะแนนกลุ่ม        12.80 / 15     │  data-testid="score-group"
│   คะแนนรายบุคคล      4.13 / 5      │  data-testid="score-individual"
│   ─────────────────────────────    │
│   รวม               16.93 / 20     │  data-testid="score-total"
│                                    │
│ ┌────────────────────────────────┐ │
│ │ การเข้าร่วมประเมิน               │ │
│ │ ส่งแล้ว 15 / 15  →  p = 1.00    │ │  data-testid="participation"
│ │ ตัวคูณ M = 1.00                 │ │  FR-SCORE-13 — เห็นแบบ real-time
│ │ (ถึงเกณฑ์ 0.90 แล้ว)            │ │
│ └────────────────────────────────┘ │
└────────────────────────────────────┘
```

**กรณีข้อมูลยังไม่พอ** (FR-ANON-02 — ผู้ประเมินยังส่งไม่ถึง k_min = 3)

```
│   คะแนนรายบุคคล                    │
│   ┌──────────────────────────────┐ │
│   │ ยังมีข้อมูลไม่พอที่จะแสดง      │ │  data-testid="score-withheld"
│   │ (ต้องมีผู้ประเมินอย่างน้อย 3   │ │
│   │  คนจึงจะเปิดเผยได้)           │ │
│   └──────────────────────────────┘ │
```

**สิ่งที่ห้ามมีในหน้านี้เด็ดขาด**

| ห้ามมี | เหตุผล |
|---|---|
| กราฟคะแนนย้อนหลัง / ตัวเลข delta | เห็น 0.62 เมื่อวาน 0.55 วันนี้ + รู้ว่ามีเพื่อนเพิ่งส่ง 1 คน = เดาออกทันทีว่าใครให้ต่ำ (FR-ANON-03) |
| จำนวนผู้ประเมินที่แน่นอน | ในกลุ่มเล็กมันคือการนับหัวเพื่อน |
| คะแนนของเพื่อนร่วมกลุ่ม | FR-REPORT-06 |
| ชื่อ/นามแฝงของผู้ประเมิน | FR-ANON-01 — ข้อที่ §19 บอกว่าห้ามตัด |

## 3. Instructor — Publish & Coverage

หน้าที่ตัดสินว่าระบบ "พังเงียบ" หรือ "บอกความจริง"

```
┌──────────────────────────────────────────────────┐
│ PairEval — SDPX 2/2569         [อ.สมชาย ▾]       │
├──────────────────────────────────────────────────┤
│ Assignment 2                        [DRAFT]      │
│                                                  │
│ ┌── ตรวจความเป็นไปได้ก่อน publish ─────────────┐  │  FR-PAIR-04
│ │                                              │  │
│ │  ⚠ coverage ถูกลดจาก 5 → 4                   │  │  data-testid="feasibility-warning"
│ │                                              │  │
│ │  ห้องนี้มี 3 กลุ่ม แต่ละคู่มีผู้มีสิทธิ์ประเมิน │  │  FR-PAIR-05
│ │  เพียง 4 คน จึงตั้ง coverage ได้สูงสุด 4 ครั้ง │  │  ← บอกเป็นตัวเลข
│ │  ต่อคู่ (ไม่ใช่ 5 ตามค่าตั้งต้น)              │  │     ไม่ใช่ "เตือน" ลอย ๆ
│ │  นักศึกษาแต่ละคนจะได้ 1 คู่ต่อเกณฑ์            │  │
│ │                                              │  │
│ │  คู่ทั้งหมด 3 · comparison รวม 12            │  │

│ └──────────────────────────────────────────────┘  │
├──────────────────────────────────────────────────┤
│ Pair Coverage Report                             │  FR-REPORT-03
│                                                  │
│ คู่                 coverage  ส่งแล้ว  flag       │
│ ─────────────────────────────────────────────    │
│ Aurora × Borealis      4        4      —         │
```

**สิ่งที่ทำให้หน้านี้มีค่า**

หน้านี้คือจุดเดียวที่กันไม่ให้ระบบ "พังเงียบ" ถ้าไม่มีมัน อาจารย์จะ publish
ด้วย coverage 5 ในใจ แล้วได้ 4 จริง โดยไม่มีใครรู้จนกว่าจะมีคนอุทธรณ์คะแนน
