# คำถามที่ requirement ยังตอบไม่ได้

> WS-02 homework ข้อ 4 · คำถามพวกนี้คือช่องที่ทั้งคนและ AI จะ "เดาแทน" ให้ถ้าเราไม่ตอบเอง
>
> เกณฑ์ที่ใช้เลือก 3 ข้อนี้: **ตอบต่างกันแล้วโค้ดต้องเขียนต่างกัน** ไม่ใช่แค่คำถามที่ยังไม่รู้คำตอบ

---

## Q1 — ห้องที่มี "2 กลุ่ม" ควรทำอย่างไร

**คำถาม:** ถ้า classroom หนึ่งมีแค่ 2 กลุ่ม — group evaluation ยังมีความหมายไหม
หรือควรปิดไปเลย

**ทำไมถึงยังตอบไม่ได้:** PRD §17 OQ-8 บอกว่า default คือ "เตือนแต่ยังทำได้"
แต่ทางคณิตศาสตร์แล้วมันทำไม่ได้เลย — มี pair เดียวคือ {A, B} และนักศึกษาทุกคน
อยู่ในกลุ่ม A หรือ B ดังนั้น **ไม่มีใครมีสิทธิ์ประเมิน pair นั้นเลยสักคน**
(constraint (1) ใน §8.2 ให้ `P − (N−1) = 1 − 1 = 0`)

**ถ้าไม่ตอบ AI จะเดาว่า:** "เตือนแล้วปล่อยผ่าน" ตาม default ใน PRD แล้ว
generate pair ที่ไม่มีใครตอบได้ — นักศึกษาเปิดหน้า evaluation แล้วเจอหน้าว่าง
โดยไม่มีคำอธิบาย

**ทางเลือกที่เป็นไปได้**

| ทางเลือก | ผลต่อโค้ด |
|---|---|
| ปฏิเสธไปเลย (ที่ทำอยู่ตอนนี้) | `solve_group_feasibility` raise — ต้องมีข้อความบอกอาจารย์ว่าทำไม |
| ให้อาจารย์ประเมินเองฝ่ายเดียว | ต้องทำ pair ที่ evaluator เป็น instructor เท่านั้น = feature ใหม่ |
| ปิด group evaluation ให้อัตโนมัติ เหลือแต่ individual | ต้องแยก state "group side disabled" ออกจาก `group_max_score = 0` |

**ตอนนี้ทำแบบไหน:** ปฏิเสธ พร้อมข้อความอธิบาย · **ใครตัดสิน:** อาจารย์ · **ต้องรู้ก่อน:** M2

## Q2 — Participation multiplier ควรคูณคะแนนทั้งก้อน หรือเฉพาะส่วน individual

**คำถาม:** นักศึกษาที่ไม่ประเมินเพื่อน ควรโดนหักเฉพาะคะแนนส่วนตัวของตัวเอง
หรือหักคะแนนกลุ่มที่ตัวเองได้รับด้วย

**ทำไมถึงยังตอบไม่ได้:** เป็นนโยบายของวิชา ไม่ใช่เรื่องเทคนิค — และผลต่างมันใหญ่มาก
จาก worked example §9.5 กรณีของ "ต้น":

| นโยบาย | คะแนนของต้น |
|---|---|
| คูณทั้งก้อน (default ปัจจุบัน) | (12.798 + 3.660) × 0.667 = **10.97 / 20** |
| คูณเฉพาะ individual | 12.798 + (3.660 × 0.667) = **15.24 / 20** |

ต่างกัน **4.27 คะแนน** จากคนคนเดียวกัน งานชิ้นเดียวกัน — เปลี่ยนเกรดได้ทั้งตัว

**ถ้าไม่ตอบ AI จะเดาว่า:** ใช้ default ใน PRD (คูณทั้งก้อน) โดยไม่บอกว่ามันเป็น
การตัดสินใจ และนักศึกษาจะรู้ตัวตอนเห็นคะแนนแล้ว ซึ่ง FR-SCORE-12 บอกว่า
ต้องประกาศตั้งแต่เปิด assignment

**ตอนนี้ทำแบบไหน:** คูณทั้งก้อน (`final_personal_score`) · **ใครตัดสิน:** อาจารย์ + ฝ่ายวิชาการ · **ต้องรู้ก่อน:** M2

## Q3 — ถ้าเปลี่ยนกลุ่มกลางเทอม comparison ที่ส่งไปแล้วจะเป็นอย่างไร

**คำถาม:** นักศึกษาย้ายกลุ่ม (หรือถอนรายวิชา) หลัง publish แล้ว —
comparison ที่คนอื่นส่งมาเกี่ยวกับกลุ่มเดิมของเขา ยังนับอยู่ไหม

**ทำไมถึงยังตอบไม่ได้:** PRD ตอบไว้ครึ่งเดียว FR-PAIR-11 บอกว่าต้อง
unpublish → แก้ → publish ใหม่ และ DR-02 บอกว่าห้ามลบ `pair_assignment`
ที่มี comparison SUBMITTED แล้ว — แต่**ไม่ได้บอกว่าคะแนนที่คำนวณจาก
comparison เก่าจะยังใช้ได้ไหม** ส่วน OQ-4 (คนถอนรายวิชา) ก็ยังรอ registrar

**ถ้าไม่ตอบ AI จะเดาว่า:** regenerate ทับไปเลย แล้ว comparison เก่ากลายเป็น
กำพร้า — หรือแย่กว่านั้นคือยังถูกนับอยู่ ทำให้กลุ่มใหม่ได้คะแนนจากงานของกลุ่มเก่า

**ทางเลือกที่เป็นไปได้**

| ทางเลือก | ผลที่ตามมา |
|---|---|
| ทิ้ง comparison เก่าทั้งหมด | ยุติธรรมที่สุด แต่เสียข้อมูลที่นักศึกษาใช้เวลาทำไปแล้ว และ coverage ตกฮวบ |
| เก็บไว้แต่ตัดออกจากการคำนวณ (`EXCLUDED`) | ตรงกับ DR-02 มากที่สุด แต่ต้องมี UI บอกอาจารย์ว่ามีกี่อันที่ถูกตัด |
| เก็บไว้และยังนับ ถ้ากลุ่มเดิมยังอยู่ | ซับซ้อนที่สุด และอธิบายให้นักศึกษาเข้าใจยาก |

**ตอนนี้ทำแบบไหน:** ยังไม่ได้ทำเลย — `generation` column มีอยู่แล้วใน model
แต่ยังไม่มี logic ที่ใช้มัน · **ใครตัดสิน:** อาจารย์ + registrar · **ต้องรู้ก่อน:** M2
